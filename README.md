# ריטריט ליום כיפור

אתר בעברית ובכיווניות מימין לשמאל, עם תרגול לערב ולבוקר יום כיפור.

## הקבצים
- `index.html` — הכותרת, ההקדמה, פתיחות החלקים והסיכום.
- `app.js` — טקסטי התרגילים והשאלות, אקורדיונים, שמירת כתיבה והדפסה.
- `style.css` — צבעים, גופן, עיצוב והתאמה לנייד ולהדפסה.
- `heebo.ttf` — הגופן המקומי; הרישיון נמצא ב־`heebo-license.txt`.

## הפעלה
אין צורך בהתקנת חבילות או בבנייה. אפשר להגיש את תיקיית האתר בכל שירות אחסון לאתרים סטטיים.

לתצוגה מקומית, הריצי בתיקייה:
```sh
python3 -m http.server 8000
```
ואז פתחי `http://localhost:8000`.

## עריכת תוכן
טקסטי התרגילים נמצאים ב־`app.js`. קישורים אופציונליים מתווספים במיפוי `activityLinks`, באמצעות רשומות עם `label` ו־`url`.
שמרי על מזהי שדות קיימים כדי לא לשנות את הקישור לתשובות שכבר נשמרו.

## פרטיות
התשובות נשמרות רק ב־localStorage בדפדפן של המבקרת. הן אינן נשלחות לשרת ואינן נכללות במאגר.
הכתיבה יכולה להימחק אם מנקים נתוני דפדפן. מעבר לכתובת אתר אחרת אינו מעביר את התשובות שנשמרו בכתובת הקודמת.
